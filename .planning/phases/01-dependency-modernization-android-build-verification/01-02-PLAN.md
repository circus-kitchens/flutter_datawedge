STEP 1: Rewrite generate.sh with updated Pigeon CLI syntax (per D-08).

Old generate.sh uses:
- `flutter pub run pigeon` (deprecated)
- `--experimental_kotlin_out` flag (removed in Pigeon 22+)
- `--experimental_kotlin_package` flag (removed)

New generate.sh must use:
```bash
#!/bin/bash
set -e

dart run pigeon \
  --input pigeons/datawedge_pigeon.dart \
  --dart_out lib/src/pigeon.dart \
  --kotlin_out android/src/main/kotlin/com/circuskitchens/flutter_datawedge/pigeon/Pigeon.kt \
  --kotlin_package "com.circuskitchens.flutter_datawedge.pigeon"
```

Make the script executable: `chmod +x generate.sh`

STEP 2: Run Pigeon code regeneration from the project root:
```bash
cd /Users/m277439/Dev/flutter_datawedge && dart run pigeon \
  --input pigeons/datawedge_pigeon.dart \
  --dart_out lib/src/pigeon.dart \
  --kotlin_out android/src/main/kotlin/com/circuskitchens/flutter_datawedge/pigeon/Pigeon.kt \
  --kotlin_package "com.circuskitchens.flutter_datawedge.pigeon"
```

If pigeon is not available as a direct `dart run pigeon` command, run it via: `dart run pigeon:pigeon` or `flutter pub run pigeon` as a fallback, but update generate.sh to use whichever form works. The key requirement is removing --experimental_kotlin_out and --experimental_kotlin_package.
